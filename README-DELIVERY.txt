Quran Portal — المصدر ونسخة HTML المتوافقة مع المسارات الفرعية

source/: مشروع Next.js، وفيه سير عمل GitHub Pages الذي يضبط basePath بحسب اسم المستودع.
static-html/: نسخة HTML نقية بمسارات نسبية، مع كل ملفات CSS وJavaScript والصور والعامل الخدمي.

يمكن نشر محتويات static-html داخل مسار فرعي. استخدم source إذا أردت البناء والنشر عبر GitHub Actions.
تحتاج ميزات الشبكة إلى استضافة HTTP/HTTPS؛ لا تفتح index.html مباشرة ببروتوكول file://.
الملفات الخام التي تتضمن بيانات تواصل شخصية غير مضمّنة؛ خلاصة متطلبات منقحة في source/docs/reference-summary.md.
